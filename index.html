STATEHow is a state represented?
A 9-tuple read row by row; □ is the blank. 9! = 362,880 arrangements, half of them reachable from any given one.
INITIALWhich arrangement do we start from?
(7, 2, 4, 5, □, 6, 8, 3, 1)
The arrangement on the slide. 26 moves is the shortest solution — confirmed by A* below.
ACTIONS(s)Which actions are applicable here?
Named for the direction the blank travels. A corner blank gives 2 actions, an edge 3, the centre 4 — mean branching factor ≈ 2.67.
RESULT(s,a)What does the transition model do?
RESULT(s, Up)
Swaps the blank with the neighbouring tile. Hover or focus an action above to preview its result.
IS-GOAL(s)What counts as a goal?
Goal state

COSTWhat is the action and path cost?
c(s, a, s′) = 1  ⟹  g(n) = 0
Every slide costs the same, so path cost is just the number of moves and breadth-first search already returns an optimal plan — at a price you can measure below.

Both never overestimate, and h₂ ≥ h₁ everywhere — that dominance is exactly what the node counts below make visible.
